🛡️ X-Purge Open Source

Outil d'automatisation de blocage pour X (Twitter) — sans extension, sans clé API, 100% exécuté localement dans votre navigateur.

1. Installer le Bookmarklet

Affichez la barre de favoris de votre navigateur (Ctrl + Maj + B sous Windows ou Cmd + Maj + B sous Mac), puis glissez-déposez ce bouton directement dedans :

🛡️ X-Purge
👆 Glissez ce bouton vers votre barre de favoris

2. Préparez votre liste personnelle

X-Purge fonctionne avec vos propres listes de comptes. Vous pouvez coller du texte directement ou importer un fichier .txt respectant ce format simple :

# Les lignes commençant par # ou vides sont ignorées
pseudo1
@pseudo2
autre_compte

✓ Un compte par ligne
✓ Le caractère @ est facultatif (pris en charge automatiquement)
✓ Vous pouvez reprendre l'exécution à tout moment grâce à l'index de départ

3. Mode d'emploi

  1. Connectez-vous sur votre compte sur x.com.
  2. Cliquez sur votre favori 🛡️ X-Purge : le panneau de contrôle s'ouvre directement sur la page.
  3. Glissez votre fichier .txt dans la zone prévue (ou collez votre liste de pseudos).
  4. Cliquez sur Démarrer le blocage. Vous pouvez mettre en pause ou arrêter à tout moment.

4. Confidentialité & Fonctionnement local

🔒 100% Local Tout s'exécute côté client dans votre propre navigateur. Aucune donnée n'est collectée ni envoyée.
⚡ Zéro extension requise Fonctionne via un simple bookmarklet JavaScript sans installer d'extension tierce.
📂 Vos propres listes L'outil est strictement neutre : vous restez seul maître des comptes que vous choisissez de bloquer.
